# Pesquisa de base do Prumo

Objetivo: toda decisão do app (diagnóstico, plano, rotina, design, sons, textos) deve
apoiar-se em evidência, ou ser assumida explicitamente como escolha de marca.

## Selos de evidência

| Selo | Significado |
|---|---|
| 🟢 **Forte** | Meta-análise ou vários experimentos randomizados convergentes |
| 🟡 **Moderada** | Experimentos isolados, amostras pequenas, ou contexto diferente do nosso |
| 🔴 **Fraca** | Estudos correlacionais, teoria sem teste, ou consenso de praticantes |
| ⚪ **Escolha de marca** | Não é ciência; é decisão de identidade, e tudo bem, desde que assumida |

Regra: só citamos números que conferimos na fonte (abstract ou artigo). O que ainda não
foi conferido fica marcado como **[a verificar]**.
