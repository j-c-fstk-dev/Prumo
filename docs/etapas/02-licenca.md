# Etapa 02: Licença AGPL-3.0

**Data:** 2026-10-17 · **Commit:** `9e757eb`

- `LICENSE` com o texto oficial da GNU AGPL v3, obtido da lista SPDX
  (o gnu.org está bloqueado na rede deste ambiente)
- Identificador: **AGPL-3.0-or-later** (cabeçalhos SPDX, `package.json`, README)
- Link **"Código-fonte (AGPL-3.0)"** no perfil do app, aponta para o repositório no GitHub

## O que isso significa na prática

- Qualquer pessoa pode ver, usar e modificar o código, **mas quem distribuir ou oferecer
  uma versão modificada pela internet precisa abrir o código dessa versão** sob a mesma licença.
- Como titulares dos direitos, vocês podem continuar vendendo o app e até licenciar o código de outra
  forma no futuro. Para manter essa liberdade quando houver contribuições de terceiros,
  use um **CLA** (acordo de cessão de contribuição) antes de aceitar código externo.
- **A seção 13 da AGPL** exige oferecer o código a quem usa o app pela rede. Por isso existe
  o link no perfil. **Se o repositório for privado, esse link não funciona para o público.**
  A licença só faz sentido completo com o repositório público.
- A **marca "Prumo"** não é coberta pela licença. A proteção vem do registro no INPI.
